# Постановка контрольной работы №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

КР №2 проверяет умение собрать интерфейс учебного магазина на CSS-фреймворке.
Основной вариант — Bootstrap. По согласованию с преподавателем можно использовать
Tailwind CSS или Bulma, если сохраняются сетка, карточки, формы, модальное окно
и навигация.

КР №2 не является адаптацией этого репозитория. Это отдельная реализация той же
предметной области: интернет-магазин, каталог, карточки товаров, заявка, навигация,
модальное окно и единый визуальный стиль. Работа сдаётся в новом репозитории.
В СДО указывается ссылка на этот репозиторий.

## Что сдаётся

```text
kr2-bootstrap-shop/
├── index.html
├── catalog.html
├── product.html
├── order.html
├── css/
│   └── custom.css
└── README.md
```

Bootstrap можно подключить через CDN или локально, если преподаватель указал
локальный вариант. Страница `contacts.html` не обязательна и может быть добавлена
как расширение.

## Обязательные элементы

| Элемент | Реализация на Bootstrap |
| --- | --- |
| Сетка | `container`, `row`, `col-*` |
| Навигация | `navbar` |
| Карточки | `card` |
| Кнопки | `btn` и варианты кнопок |
| Формы | `form-control`, `input-group`, `form-check` |
| Модальное окно | `modal` |
| Сообщения | `alert` |
| Значки | `badge` |
| Дополнительно | `accordion`, вкладки или `carousel` — по выбору |

## Страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | Навигация Bootstrap, hero-блок и карточки |
| `catalog.html` | Каталог товаров в сетке Bootstrap |
| `product.html` | Карточка товара, характеристики, цена и `badge` |
| `order.html` | Форма заявки или заказа на элементах Bootstrap |

## README
